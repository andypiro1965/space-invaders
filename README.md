# Space Invaders

Gioco arcade nel browser in HTML, CSS e JavaScript, in un unico file e senza librerie esterne.

**Gioca subito:** https://andypiro1965.github.io/space-invaders/

## Come giocare
- **Muovi:** frecce sinistra/destra oppure A/D.
- **Spara:** barra spaziatrice o freccia su.
- **Pausa:** P. **Riavvia dopo il game over:** Invio (o tocco sullo schermo).
- **Touch:** su smartphone compaiono i pulsanti ◀ FIRE ▶.

## Caratteristiche
- 5 file di invasori (50 alieni) che accelerano man mano che ne restano meno
- Scudi che si danneggiano, UFO bonus, 3 vite
- Livelli crescenti con difficoltà progressiva
- Record salvato nel browser, effetti sonori

## Pubblicazione
Il workflow `.github/workflows/pages.yml` pubblica il sito su GitHub Pages a ogni push su `main`.
Se non parte, in **Settings → Pages** seleziona **GitHub Actions** come source.
