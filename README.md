# Space Invaders — Arcade Edition

Gioco arcade in HTML, CSS e JavaScript, senza librerie esterne e senza installazione.

## Come giocare
- **Muovi:** frecce sinistra/destra oppure A/D.
- **Spara:** barra spaziatrice (anche W/freccia su).
- **Touch:** usa i controlli visualizzati su smartphone.
- Elimina tutti gli alieni, evita i colpi nemici e supera le ondate.

## Pubblicazione
Il workflow GitHub Actions in `.github/workflows/pages.yml` pubblica automaticamente il sito su GitHub Pages quando viene aggiornato il branch `main`.

Se la pubblicazione non parte automaticamente, apri **Settings → Pages** nel repository e seleziona **GitHub Actions** come build and deployment source.

URL atteso: https://andypiro1965.github.io/space-invaders/
